# 🏛️ DCW-SETIF-TRACKER — منصة الرقابة والتفتيش الميداني
### مديرية التجارة الداخلية وضبط السوق الوطنية لولاية سطيف

منظومة إدارية ورقمية متكاملة لمتابعة فرق التفتيش والرقابة الميدانية، وضبط الحضور والانصراف الجغرافي، وإدارة البرامج الرقابية، وتأشير المعاينات وتوليد التقارير الرسمية لحظياً.

---

## 🚀 بنية النظام وترابط الأدوار والمهام (System Roles & Interconnection)

النظام مصمم وفق منطق إداري محكم وتدرج هرمي وظيفي حقيقي:

```
                           ┌────────────────────────┐
                           │    المسؤول التقني      │
                           │       (Admin)          │
                           └───────────┬────────────┘
                                       │ (إدارة الحسابات وتوليد البيانات لكافة الموظفين)
                                       ▼
                           ┌────────────────────────┐
                           │   المدير الولائي        │
                           │      (Director)        │
```

---

### 1. المسؤول التقني (`Admin`)
* **إدارة الحسابات والصلاحيات:** إنشاء الحسابات، إعادة تعيين كلمات المرور، تفعيل/تعطيل المستخدمين.
* **التوليد التلقائي للحسابات (Bulk Generation):** توليد حسابات دخول آمنة وفورية لكافة الموظفين المسجلين في قاعدة بيانات المديرية (267 موظفاً).

### 2. المدير الولائي (`Director`)
* **لوحة القيادة المركزية:** إحصائيات عامة وفورية لجميع موظفي المديرية والمصالح الرقابية.
* **الخريطة التفاعلية:** تتبع انتشار فرق التفتيش في مختلف دوائر وبلديات ولاية سطيف.
* **تصدير التقارير الرسمية (PDF Export):** استخراج وطباعة تقارير الحضور والغياب والمعاينات باللغة العربية مع دعم كامل للاتجاه RTL وتقسيم الصفحات.
* **عرض وطباعة رمز الاستجابة السريعة (QR Code):** إمكانية استعراض رمز الـ QR الرسمي لنقاط الحضور بالمقر.

### 3. رئيس المصلحة (`Head of Department`)
* **أوامر المهمة والبرامج الرقابية:** إنشاء مهام وتكليفات تفتيشية محددة بالدوائر، البلديات، ونوع النشاط التجاري.
* **متابعة الأعوان:** شاشة متابعة حية لحضور وغياب المفتشين التابعين للمصلحة.
* **تأشير واعتماد المعاينات:** مراجعة محاضر وتقارير التفتيش الميدانية وتأشيرها رسمياً مع إمكانية إصدار الختم الرقمي QR.

### 4. رئيس المكتب (`Bureau Chief`)
* تتبع فرق التفتيش التابعة للمكتب وتوزيع الأهداف الميدانية اليومية.

### 5. المفتش / العون الميداني (`Inspector`)
* **تسجيل الحضور الإلزامي بمسح رمز QR (حماية الخصوصية):**
  * تم إلغاء إلزامية تصوير الوجه (السيلفي) لحماية خصوصية الموظف.
  * التسجيل يتم عبر **مسح رمز الاستجابة السريعة (QR Code)** المعلق بنقطة الحضور الرسمية + **التحقق من إحداثيات الموقع الجغرافي (GPS Geofencing)** والتوقيت الدقيق للسيرفر.
* **المزامنة دون اتصال (Offline-First Sync):** حفظ وتخزين عمليات الحضور والمعاينات محلياً في حال انقطاع الإنترنت، ومزامنتها تلقائياً فور عودة الشبكة.
* **توثيق المعاينات والزيارات التجارية:** تسجيل المحل، نوع النشاط، الملاحظات، وإرفاق صور المحل التجاري / المخالفات الميدانية.

## 🌐 الروابط الرسمية للمنظومة الحية (Render Cloud)

* **رابط تطبيق الويب المباشر (Static Site):** [https://dcw-setif-tracker.onrender.com](https://dcw-setif-tracker.onrender.com)
* **خادم الـ API وقاعدة البيانات (Web Service):** `https://drh-setif-api.onrender.com/api`
* **المصادقة والأمان:** JSON Web Tokens (JWT) + تشفير كلمات المرور بـ Bcrypt.
* **قاعدة البيانات:** متوافقة وموحدة مع PostgreSQL و SQL Server.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة:** Flutter 3 (Dart) — بنية Provider لإدارة الحالة.
* **الخرائط:** Flutter Map + LatLong2 (خرائط ولاية سطيف والجزائر).
* **إدارة الحزم والأمان:** Shared Preferences (Offline Storage), QR Flutter, Geolocator, Image Picker.
* **الخادم الخلفي:** Node.js / Express / RESTful API.
