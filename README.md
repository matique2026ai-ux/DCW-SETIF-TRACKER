# 🏛️ DCW-SETIF-TRACKER — منصة الرقابة والتفتيش الميداني
### مديرية التجارة الداخلية وضبط السوق الوطنية لولاية سطيف

منظومة إدارية ورقمية متكاملة لمتابعة فرق التفتيش والرقابة الميدانية، وضبط الحضور والانصراف الجغرافي الذكي، وإدارة البرامج الرقابية، ومسار الاستفسارات القانونية وفق قانون الوظيفة العمومية، وتأشير المعاينات وتوليد التقارير الرسمية لحظياً.

---

## 🚀 بنية النظام والترابط الوظيفي الإداري (System Architecture)

النظام مصمم وفق التدرج الهرمي الإداري الحقيقي لسلطات الوظيفة العمومية:

```
                           ┌────────────────────────┐
                           │    المسؤول التقني      │
                           │       (Admin)          │
                           └───────────┬────────────┘
                                       │ (إدارة الحسابات وتوليد البيانات لكافة الموظفين وضبط الإعدادات)

                           │   المدير الولائي        │
                           │(Director / Ordonnateur)│
                           └───────────┬────────────┘
```

---

### 1. المسؤول التقني (`Admin`)
* **إدارة الحسابات والصلاحيات:** إنشاء الحسابات، إعادة تعيين كلمات المرور، تفعيل/تعطيل المستخدمين.
* **التوليد التلقائي للحسابات (Bulk Generation):** توليد حسابات دخول آمنة وفورية لكافة الموظفين (267 موظفاً).
* **ضبط فترة التسامح الصباحية:** تحديد عتبة التسامح الصباحية المعتمدة لمديرية التجارة.

### 2. المدير الولائي — الآمر بالصرف (`Director / Ordonnateur`)
* **لوحة القيادة المركزية:** إحصائيات عامة وفورية لنشاط المفتشيات، المحجوزات والمخالفات.
* **الخريطة التفاعلية الحية:** تتبع لحظي عالي الأداء (60 FPS) لانتشار الفرق الرقابية عبر دوائر وبلديات ولاية سطيف.
* **الفصل في الاستفسارات الإدارية:** مراجعة تبريرات المفتشين مع 4 قرائن إثبات رقمية (GPS، المردودية) واتخاذ القرار السيادي (قبول وحفظ / تنبيه إداري / إصدار قرار خصم نافذ).
* **ضبط فترة التسامح الصباحية:** مرونة كاملة في اختيار موعد التسامح (08:15 إلى 09:15).
* **تصدير التقارير الرسمية (PDF Export):** استخراج وطباعة تقارير الحضور والمعاينات باللغة العربية.

### 3. رئيس المصلحة (`Head of Department`)
* **أوامر المهمة والبرامج الرقابية:** إنشاء مهام وتكليفات تفتيشية محددة بالدوائر، البلديات، ونوع النشاط التجاري وتوجيهها للمفتشين.
* **تأشير واعتماد المعاينات:** مراجعة محاضر وتقارير التفتيش الميدانية وتأشيرها واعتمادها رسمياً.

### 4. رئيس مكتب المستخدمين (`Bureau Chief`)
* **متابعة ساعات التأخر التراكمية:** احتساب التأخر وفق الأمر رقم 06-03 المتضمن القانون الأساسي العام للوظيفة العمومية.
* **توجيه الاستفسارات الرسمية المطبوعة:** استخراج استمارة الاستفسار الرسمية مع مهلة 48 ساعة للموظف.
* **تنفيذ قرارات الخصم على الراتب:** تسجيل قرارات الخصم الصادرة عن المدير كمنفذة على كشف الراتب (`Exécuté sur Paie`) دون أي سلطة للاعتراض.

### 5. المفتش / العون الميداني (`Inspector`)
* **تسجيل الحضور الصباحي الذكي (حماية الخصوصية):**
  * إلغاء تصوير الوجه (السيلفي) نهائياً.
  * التسجيل بلمسة واحدة عبر البصمة الجغرافية الذكية (GPS Geofencing) بالتعرف التلقائي على المقر/المفتشية/الملحقة/المطار.
* **الرد على الاستفسارات الإدارية:** تقديم التبريرات الرسمية عبر التطبيق خلال مهلة 48 ساعة.
* **المزامنة دون اتصال (Offline-First):** حفظ وتخزين العمليات محلياً ومزامنتها تلقائياً عند توفر الشبكة.
* **توثيق المعاينات التجارية:** تسجيل المحل، نوع المخالفة، الإجراء القانوني، وقيمة المحجوزات (د.ج) مع الصور التوثيقية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية:** Flutter 3 (Dart) — بنية Provider لإدارة الحالة.
* **الخرائط:** Flutter Map + LatLong2 (خرائط ولاية سطيف والأقمار الصناعية ESRI HD).
* **إدارة الحزم والأمان:** Shared Preferences (Offline Storage), QR Flutter, Geolocator, Image Picker, PDF/Printing.
* **الخادم الخلفي:** Node.js / Express / RESTful API / PostgreSQL.
